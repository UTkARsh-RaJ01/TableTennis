
# Tennis Analysis

## Introduction
This project focuses on analyzing tennis players in video footage to track their movement speed, shot speed, and count the number of shots. It leverages YOLO for real-time detection of players and the tennis ball, while Convolutional Neural Networks (CNNs) are used to identify keypoints on the court. It's an excellent hands-on opportunity to strengthen your skills in machine learning and computer vision through real-world sports analytics.
